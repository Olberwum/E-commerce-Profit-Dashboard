# 📊 E-commerce Profit Dashboard

**Интерактивный дашборд** для анализа прибыльности интернет-магазина.  
Построен в **Tableau Public** на основе реального (синтетического) [датасета e‑commerce. ](https://www.kaggle.com/datasets/prince7489/e-commerce-sales/data) Дашборд построен без SQL-запросов в явном виде
Проект выполнен в рамках портфолио для позиции **BI / SQL / Business Analyst (Junior+/Middle)**.

🔗 [**Ссылка на дашборд:**

## 🎯 Бизнес-задача

Определить ключевые факторы, влияющие на прибыль:
- Какие категории товаров и регионы приносят основную прибыль?
- Какие клиенты и товары наиболее ценны?

## 🧹 Очистка данных (Data Cleaning)

Перед построением дашборда датасет был обработан:
- Удалены дубликаты заказов (3 строки)
- Обработаны пропуски в поле `Discount` (заполнены 0)
- Проверены и удалены выбросы (2 заказа с отрицательной выручкой)
- Тип поля `Order_Date` приведён к формату `DATE`
- Экспортирован чистый CSV для Tableau

---

> Все фильтры на дашборде (дата, регион, категория) работают глобально, имитируя параметризацию SQL-запросов через `WHERE`.

## 📌 Выводы (Insights)

- **Electronics** — лидер по прибыли среди всех категорий (~25% от общей), Clothing имеет низкую маржинальность (8–9%).
- **Распределение по способам оплаты** почти равномерное: Credit Card (22%), Debit Card (21%), UPI (20%), COD (19%), Net Banking (18%).
- **Топ-5 клиентов** приносят суммарно ~12% от всей выручки.
- **Скользящее среднее прибыли** показывает устойчивый рост с весны 2025 года после пост-новогоднего спада в январе–феврале.
